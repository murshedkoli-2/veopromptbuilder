# 🤖 Veo Prompt Builder — Interactive AI Prompt Generator

[![Next.js](https://img.shields.io/badge/Next.js-15.0-black?style=for-the-badge&logo=next.js)](https://nextjs.org/)
[![NextAuth](https://img.shields.io/badge/Auth-NextAuth.js-purple?style=for-the-badge)](https://next-auth.js.org/)
[![MongoDB](https://img.shields.io/badge/Database-MongoDB-47A248?style=for-the-badge&logo=mongodb)](https://www.mongodb.com/)
[![Framer Motion](https://img.shields.io/badge/Animation-Framer_Motion-0055FF?style=for-the-badge&logo=framer)](https://www.framer.com/motion/)

An interactive web application engineered to generate high-precision, optimized creative prompts for state-of-the-art AI video and image models (such as Google Veo, Sora, Midjourney, and Stable Diffusion).

---

## 🌟 Key Features

- **🎬 Video Style & Camera Parameter Controls**: Fine-tune cinematic camera angles (Drone, Close-up, Dolly Zoom), lens types, frame rates, lighting (Golden Hour, Cyberpunk, Volumetric), and mood.
- **⚡ Instant Prompt Synthesis**: Real-time prompt compilation combining subject, aesthetics, environment, and motion cues into ready-to-copy prompt strings.
- **💾 Saved Prompts Library**: Save favorite prompt combinations to MongoDB with authenticated user profiles via NextAuth.
- **🎨 Engaging Visual UI**: Fluid motion effects and sleek UI built with Framer Motion and Lucide Icons.

---

## 🚀 Setup & Launch

```bash
git clone https://github.com/murshedkoli-2/veopromptbuilder.git
cd veopromptbuilder
npm install
npm run dev
```
